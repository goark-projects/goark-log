# Goark Log 0.0.3

[English](https://github.com/goark-projects/goark-log/blob/v0.0.3/docs/releases/v0.0.3.md) | 中文

发布日期：2026 年 9 月 7 日

Goark Log 0.0.3 在保持既有显式 Go 日志契约的同时，加强了生产配置、结构化输出、
滚动文件可靠性和框架集成。

精简版本历史见[变更日志](https://github.com/goark-projects/goark-log/blob/v0.0.3/CHANGELOG.zh-CN.md#v003---2026-09-07)。

## :star: 版本亮点

- 新增 Spring Boot 风格控制台布局、Logger 名称缩写、结构化 JSON 格式、可配置输出字符集和运行时级别控制。
- 支持内存配置和已加载选项定制，无需临时文件。
- 加强启动、按大小滚动、保留策略和配置重载行为。
- 公共根包保持为 `log`，实现细节按职责拆分到内部包。
- JSON 编码统一使用 Sonic，并要求 Go 1.26 或更高版本。

## :package: 安装

```bash
go get goark.dev/log@v0.0.3
```

## :information_source: 兼容性

- 模块要求 Go 1.26 或更高版本。
- 根包是 `log`，与 `goark.dev/log` 保持一致。
- 继续支持显式 Appender、Layout、Filter、Plugin 和 `slog.Handler` 集成。

## :white_check_mark: 验证

候选版本已在 Windows 和 Debian Linux 上通过模块校验、测试、vet、race、静态分析、
漏洞扫描和源码结构门禁。CI 会重复执行支持的跨平台检查。
