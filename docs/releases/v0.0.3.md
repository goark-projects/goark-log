# Goark Log 0.0.3

English | [中文](https://github.com/goark-projects/goark-log/blob/v0.0.3/docs/releases/v0.0.3.zh-CN.md)

Release date: September 7, 2026

Goark Log 0.0.3 strengthens production configuration, structured output,
rolling-file reliability, and framework integration while preserving the
explicit Go logging contracts introduced by earlier releases.

See the [changelog](https://github.com/goark-projects/goark-log/blob/v0.0.3/CHANGELOG.md#v003---2026-09-07)
for the concise version history.

## :star: Highlights

- Add Spring Boot-style console layouts, logger-name abbreviation, structured
  JSON formats, configurable output charsets, and runtime level control.
- Support in-memory configuration and loaded-options customization without
  temporary files.
- Strengthen startup, size-based rolling, retention, and configuration reload.
- Keep the public root package named `log` and split implementation details
  into responsibility-focused internal packages.
- Standardize JSON encoding on Sonic and require Go 1.26 or later.

## :package: Installation

```bash
go get goark.dev/log@v0.0.3
```

## :information_source: Compatibility

- The module requires Go 1.26 or later.
- The root package is `log`, matching `goark.dev/log`.
- Existing explicit appenders, layouts, filters, plugins, and `slog.Handler`
  integration remain supported.

## :white_check_mark: Verification

The release candidate passed module verification, tests, vet, race detection,
static analysis, vulnerability scanning, and source-structure gates on Windows
and Debian Linux. CI repeats the supported cross-platform checks.
